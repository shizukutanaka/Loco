## English

### Introduction
Loco is a professional automation platform that supports multiple languages for global users. This manual provides comprehensive guidance on using Loco's multilingual features.

### Features
- **50+ Language Support**: Full localization for interfaces and documentation.
- **AI-Powered Translation**: Real-time translation for workflows and messages.
- **Regional Adaptations**: Support for local calendars, currencies, and business practices.

### Setup
1. Install Loco CLI.
2. Run `loco config set-language <code>`.
3. Verify with `loco health`.
