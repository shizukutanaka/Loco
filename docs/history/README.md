# History

Dated analysis notes from earlier sessions. They record what was investigated
and proposed at a point in time; they are not a description of the product as
it stands. For that, read the root `README.md`.

They are kept because they propose rather than assert - unlike the twenty-four
root-level documents removed alongside them, which claimed as finished a great
deal that was never built: an AI framework, a governance engine, quantum-ready
autonomy, "7 of 7 systems implemented", "$8M-$18M additional annual savings".
Every source file those documents pointed at was absent.

`scripts/check-structure.py` now fails when any document cites a source file
that does not exist, so a document cannot quietly outlive its subject again. A
line that says outright the file is gone is exempt - being accurate about
history is the point.
